# robots.txt for media.epsteinproject.org (R2 bucket epstein-files).
#
# This host serves ~87,500 raw assets -- PDFs, page images, thumbnails, video.
# It is not where the archive is read: every document has a real page at
# epsteinproject.org/documents/<id> with the OCR text server-rendered into the
# HTML, and those pages are what can actually rank.
#
# As of 2026-07-27 Google had discovered 20,223 of those document pages and
# indexed only 2,031, which is a crawl-budget problem rather than an error.
# Letting crawlers walk 87,500 binary assets on this host spends that budget
# on files that cannot rank. Disallowing here points it back at the pages.
#
# This affects crawlers only. Visitors, the site itself, and hotlinked media
# are unaffected -- the objects stay publicly readable.
User-agent: *
Disallow: /
